# Dungeon_Crawler

Python text-based dungeon crawler where you’re trapped in a magical labyrinth after insulting an insecure wizard. To escape, you must navigate rooms, solve riddles from the wizard’s alter-ego “Riddle Masters”,  and manage your stats and inventory.

This project showcases the Python fundamentals: loops, conditionals, nested functions, data structures (lists, tuples, dictionaries), and modular readable code.

I utilized a simple game loop and state managment system (rooms, stats, inventory), a turn-based battle system, and a small shop system.
